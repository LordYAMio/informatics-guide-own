# Словарь терминов

1. **Информация** — сведения об окружающем мире.
2. **Компьютер** — электронное устройство для обработки информации.
3. **Процессор** — основная часть компьютера, выполняющая вычисления.
4. **Оперативная память (RAM)** — память для временного хранения данных.
5. **Файл** — набор данных, сохранённый под определённым именем.
6. **Операционная система** — программа, управляющая работой компьютера.
7. **Алгоритм** — последовательность действий для решения задачи.
8. **Программа** — набор команд, которые выполняет компьютер.
9. **Система счисления** — способ записи чисел с помощью определённых символов.
