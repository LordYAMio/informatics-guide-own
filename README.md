# Справочник по информатике

## Цель проекта
Создать небольшой справочник по информатике для студентов первого курса.

## Автор
Luazxk

## Тема
Системы счисления.

## Содержание проекта
- README.md — описание проекта.
- glossary.md — основные термины.
- examples.md — примеры решения задач.
- sources.md — использованные источники.
- questions.md — вопросы для самопроверки.

## Как пользоваться справочником
Сначала изучите основные термины, затем рассмотрите примеры решения задач и проверьте свои знания с помощью вопросов.
